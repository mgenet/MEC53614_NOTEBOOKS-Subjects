Exercise notebooks of MEC_53614 (*Artificial intelligence for solids and structures*, École polytechnique, Martin Genet & Ioannis Stefanou).

Each folder `En` contains the notebook of exercise n, with a copy of the course library `LIB53614`.
To work locally, use the course environment (see the environment repository), or simply `pip install numpy scipy matplotlib scikit-learn jupyterlab`.
On Colab, uncomment the `pip install` line of the first code cell.
